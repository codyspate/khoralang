These notes map familiar concepts from other ecosystems onto Khora after you have read the core Guide.

They are not syntax cheat sheets. The goal is to explain where a familiar concept has a direct analogue, where Khora deliberately chooses a different abstraction, and which habits should not be carried over unchanged.

Current guides cover TypeScript + Effect, Go, and Rust because those ecosystems overlap most directly with Khora's target use cases and design tradeoffs.
