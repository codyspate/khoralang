The Khora Guide teaches the language from the programmer's point of view.

Start with values and functions, then move through data types and pattern matching before learning the features that distinguish Khora most strongly: pipelines, typed failure, effects and capabilities, regions, structured fibers, explicit shared state, and capability-driven testing.

The Guide is intentionally different from the Language Reference. The Guide builds a mental model and recommends ordinary patterns. The Reference records precise rules for lookup.

If you are coming from TypeScript + Effect, Go, or Rust, read the core Guide first and then use the migration notes to map concepts you already know onto Khora.
