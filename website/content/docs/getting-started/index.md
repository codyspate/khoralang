This section gets a new Khora developer from a clean machine to a checked, formatted, tested, and built program.

1. Install the compiler/toolchain prerequisites.
2. Build or select a Khora compiler.
3. Check and build a first package.
4. Configure the language server and formatter.

Khora is still pre-release, so the current installation page describes a source build. The public release will replace that first step with versioned downloadable compiler artifacts while keeping the rest of the workflow stable.
