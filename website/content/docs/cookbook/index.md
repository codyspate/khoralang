The Cookbook combines several Khora features into production patterns rather than explaining one language construct at a time.

Use it for questions such as:

- how should an HTTP service bound work under overload?
- what does a cancellation-safe transaction look like?
- where should trace context enter and propagate?
- how should capabilities be replaced in tests?
- how should application configuration enter the system?

These pages complement generated API documentation. An API reference tells you what a function is; the Cookbook tells you how several APIs and language guarantees fit together in a service.
