# Documentation audit, 2026-09-09

An agent read only the public docs (`website/content/docs/**`, `README.md`,
`docs/`) looking for text that was generated rather than designed, and checked
every concrete claim against the code.

**The verdict was that the prose is not slop.** No emoji headers, no marketing
tricolons, no "Key Takeaways". `performance/`, `limitations/`, `reference/traps.md`,
`reference/compatibility.md`, `stdlib/api/db.md` and `stdlib/api/trace.md` were
called out as the opposite of generated text. Every CLI command, lint, manifest
key and ~40 spot-checked `std` signatures verified.

What it found instead was **staleness**: counts that were true once, a shipped
Dockerfile that cannot work, and pages duplicated wholesale.

## Wrong, and a reader would act on it

- `deployment/containers.md:17,27,38` — the Dockerfile builds `FROM
  debian:bookworm-slim` and installs the published toolchain, which
  `supported-targets.md:47` says three times cannot run there (glibc 2.36).
  The build stage dies on `khora --version`.
- `README.md:279` — "1,376 Rust tests and 18 Khora ones pass". There are 72
  `test` blocks in `std`/`examples`/`packages`; the Rust figure needs re-running.
- `README.md:395` — "nineteen decision records". There are 47.
- `README.md:400` vs `:434` — "four reference applications", five on disk, three
  listed.
- `README.md:481` vs `limitations/index.md:96` — the README's "what is next" says
  the M:N scheduler is unbuilt; the docs say it ships behind `KHORA_FIBERS=scheduler`.
- `limitations/index.md:267` vs `deployment/cloudflare.md:9` — one page calls
  Cloudflare "experimental", the other spends a paragraph on why that word is wrong.
- `reference/failures.md:301` — `fold_chunks`'s step is `(A, Array<U8>) -> A`,
  not `(A, String) -> A`.
- `deployment/supported-targets.md` — written entirely about 0.1.0; `linux.md:28`,
  `containers.md:27` and `README.md:204` pin 0.1.0 while the rest of the site is 0.2.
- `stdlib/api/net/tls.md:45` — "Three cases and no message". `TlsError` has four
  and `Unreachable(host)` carries one.
- `stdlib/api/net/http.md:1252` — "the four above"; there are three.
- `stdlib/api/net/socket.md:60` — "two"; the page opens by naming three.
- `reference/lexical-structure.md:266` — the contextual-keyword list omits `row`.
- `stdlib/api/core.md:3081` — `with_c_string`'s summary is `with_data`'s sentence.
- `getting-started/index.md:46-51` — `khora new` also writes `.gitignore`, which
  the tree omits and `first-project.md:129` relies on.
- `cookbook/taking-work-off-a-queue.md:33` — `serve(board, job)!` uses a `board`
  that appears nowhere; the working example at :79 takes one argument.

## Generator, not prose

`stdlib/api/core.md:4725-6066` — 44 of 78 "Trait implementations" sections are a
heading, an `impl` fence, a member heading and a signature fence with no prose:
twenty screens of it, and the largest volume of empty text on the site. `khora
doc` should collapse prose-free impls into one `Trait for Type` table. Same at
`stdlib/api/schema.md:715ff`.
